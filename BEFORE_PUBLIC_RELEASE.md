# Before Public Release

The repository package is ready for public upload.

Please complete the following items after creating the public repository / Zenodo record:

1. Replace `REPLACE_WITH_GITHUB_OR_PUBLIC_REPOSITORY_URL` in `CITATION.cff`
   with the final public repository URL.
2. Replace `REPLACE_WITH_ZENODO_DOI` in `CITATION.cff`
   with the DOI assigned by Zenodo.
3. When the article receives a DOI, replace
   `REPLACE_WITH_ARTICLE_DOI_WHEN_AVAILABLE` in `CITATION.cff`.
4. Confirm that the contact email and author names are correct before release.

The repository uses a custom permission-required academic license.
Reuse in new research projects, derivative work, redistribution, publication,
or commercial activity requires prior written permission. Authorized academic
use must cite the associated publication and repository.
