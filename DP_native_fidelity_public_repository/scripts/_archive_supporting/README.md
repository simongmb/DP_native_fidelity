# Archived supporting / cross-context analyses

These scripts are retained for provenance and auditability. They represent exploratory or cross-context analyses performed during manuscript development.

They are **not** used as independent external validation of the complete anatomy-referenced discovery pipeline and should not be described that way in the manuscript or repository documentation.

The main reproducibility path is the numbered `01`–`07` scripts at `scripts/` plus the finalized figure scripts.
